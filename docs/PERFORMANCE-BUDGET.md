# 第二輪壓力檢查：量測前界線

2026-11-20，先固定預算再量測。目的為確認複雜合成文件能進入審查，不代表正式產品負載分布。

- 主案例：12 章、60 個不同的交班／檢查段落、36 個跨區服務列、8 欄、巢狀收合／引用／表格／媒體、長 URL、11 個變動區塊。各章有不同操作脈絡，沒有用重複同一句填充壓力。
- 本機 Node pure compare：暖機後 25 次，p95 ≤250ms。
- 真實瀏覽器：主案例載入／重建畫面含下一 frame 的表格列高同步 ≤1000ms，兩種模式均檢查；展開完整文件不造成頁面橫向溢出。此值是應用自行記錄的 render-to-frame 時間，非工具往返或真人反應時間。
- 故障：超出既有上限與無效結構明確失敗；長文字 diff 工作量有界。沒有聲稱 12000 nodes 以下皆達相同延遲。
- 不滿足預算先找反例並修正；不以修改預算使結果通過。正式產品需另取得大小分布、低階設備與瀏覽器版本。
